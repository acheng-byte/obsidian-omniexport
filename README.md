# OmniExport / 万能导出

[English](README_EN.md) | [中文](README.md)

> Obsidian 万能 HTML 导出插件 — 自包含单文件、交互式、手机端优先、多平台发布

## 功能特性

### 自包含单文件 HTML

导出的 HTML 将 CSS、JavaScript、图片/视频/音频全部内嵌到一个 `.html` 文件中，无需任何外部依赖，离线也能完美显示。分享给任何人都能直接打开。

### 6 套文档主题

| 主题 | 适用场景 |
|------|----------|
| 默认 | 通用笔记导出 |
| 公文（GB/T 9704-2012） | 正式公文、红头文件 |
| 报告 | 工作报告、项目报告 |
| 演示 | 幻灯片风格展示 |
| 工程 | 工程报表、技术文档（蓝色专业风格） |
| 销售 | 销售报表、业绩汇报（绿色数据风格） |

所有主题均支持暗色/亮色模式，导出的 HTML 可运行时切换主题，无需重新导出。

### 多文件格式支持

| 文件类型 | 支持格式 | 导出方式 |
|----------|----------|----------|
| Markdown | `.md` | 完整渲染 |
| 文本 | `.txt` `.csv` `.json` `.yaml` `.log` | 保留格式排版 |
| 图片 | `.png` `.jpg` `.gif` `.svg` `.webp` `.bmp` | base64 内嵌 |
| 视频 | `.mp4` `.webm` `.mov` `.avi` `.mkv` | base64 内嵌 |
| 音频 | `.mp3` `.wav` `.ogg` `.flac` `.aac` `.m4a` | base64 内嵌 |

### 交互式功能（可选）

开启后导出的 HTML 自带工具栏：

- 目录导航（自动生成，侧栏滑出）
- 全文搜索（200ms 防抖，安全文本处理）
- 暗色/亮色切换（右下角浮动按钮）
- 主题运行时切换（6 主题下拉选择）
- 可编辑表格（单元格可编辑，支持重置和导出 CSV）
- 任务列表进度条（自动统计完成比例）
- 文件导入（支持 Excel/Word/CSV 导入到页面中）

### 资源内嵌引擎

Markdown 中引用的图片、视频、音频自动解析并转为 base64 data URI。支持 5 种路径解析策略：

- `app://` URL（桌面端 Obsidian 渲染）
- `content://` URL（移动端）
- MetadataCache 解析（wikilink / 相对路径）
- 直接路径查找
- 文件名全局搜索

### 渲染保留

可选开启的渲染功能：

- Mermaid 图表（CDN 加载）
- 数学公式 MathJax（CDN 加载）
- 代码语法高亮 highlight.js（CDN 加载）
- SEO 与 Open Graph 标签

### 批量导出

一键导出整个 Vault，自动过滤不可导出的文件类型，实时显示导出进度。

### 自定义输出路径

支持自定义输出目录，内置文件夹选择器，全平台兼容（电脑 / Android / iOS）。

### 手机端优先

所有导出页面均采用响应式设计，手机端完美的阅读体验。插件本身也完全兼容 Obsidian 移动端。

### 自动更新

支持启动时自动检测新版本，也可在设置页手动检查更新并跳转到 Release 页面下载。

## 快速开始

1. 在 Obsidian 社区插件市场搜索 **OmniExport** 并安装
2. 在设置中选择语言和主题偏好（默认最简 MD 渲染模式，按需开启高级功能）
3. 使用命令面板 (`Ctrl/Cmd + P`) 搜索：
   - `导出当前笔记为 HTML` — 导出当前文件
   - `批量导出整个仓库` — 导出整个 Vault
   - `检查插件更新` — 手动检查更新
   - `查看导出日志` — 查看导出日志（默认仅显示错误）

## 设置项

| 设置 | 说明 | 默认 |
|------|------|------|
| 语言 | 中文 / English | 中文 |
| 主题 | 浅色 / 深色 / 跟随系统 | 跟随系统 |
| 文档主题 | 6 套主题选择 | 默认 |
| 内嵌资源 | 图片/视频/音频内嵌为 base64 | 开启 |
| 交互功能 | 工具栏/搜索/目录/主题切换 | 关闭 |
| Mermaid | 渲染 Mermaid 图表 | 关闭 |
| 数学公式 | 渲染 LaTeX 公式 | 关闭 |
| 代码高亮 | 语法高亮 | 关闭 |
| SEO | 生成 Open Graph 标签 | 关闭 |
| 输出目录 | 自定义输出路径 | 笔记同目录 |
| 自动更新 | 启动时自动检测新版本 | 开启 |
| 检查更新 | 手动检查并下载更新 | — |
