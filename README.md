# OmniExport / 万能导出

[English](README_EN.md) | [中文](README.md)

> Obsidian 万能 HTML 导出插件 — 自包含、交互式、手机端优先、多平台发布

## ✨ 功能特性

### 1. 自包含单文件 HTML
将 CSS、JavaScript、图片全部内嵌到一个 `.html` 文件中，无需任何外部依赖，分享给任何人都能直接打开。

### 2. 交互式导出
-  自动生成目录导航
- 🔍 全文搜索
- 🌓 暗色/亮色主题切换
- 📂 折叠块支持

### 3. 批量发布
一键导出整个 Vault 为静态 HTML 网站，自动处理内部链接。

### 4. 多平台分发
支持导出为适配微信公众号、知乎、Medium、WordPress 等平台的格式。

### 5. SEO 与社交卡片
自动生成 Open Graph 标签，分享到社交媒体时自动显示精美预览。

### 6. 完整渲染保留
- Mermaid 图表 ✅
- 数学公式 (MathJax) ✅
- 代码语法高亮 ✅
- 任务列表 ✅

### 📱 手机端优先
所有导出页面均采用响应式设计，在手机端有完美的阅读体验。

## 🚀 快速开始

1. 在 Obsidian 社区插件市场搜索 **OmniExport** 并安装
2. 在设置中选择语言和主题偏好
3. 使用命令面板 (`Ctrl/Cmd + P`) 搜索：
   - `导出当前笔记为 HTML` — 导出当前文件
   - `批量导出整个仓库` — 导出整个 Vault
