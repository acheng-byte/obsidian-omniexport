# OmniExport

[中文](README.md) | [English](README_EN.md)

> Universal HTML Export Plugin for Obsidian — Self-contained, Interactive, Mobile-First, Multi-Platform Publishing

## ✨ Features

### 1. Self-Contained Single-File HTML
Embeds CSS, JavaScript, and images into a single `.html` file. No external dependencies — share it with anyone and it just works.

### 2. Interactive Export
- 📑 Auto-generated table of contents
- 🔍 Full-text search
- 🌓 Dark/Light theme toggle
- 📂 Collapsible sections

### 3. Batch Publishing
Export your entire vault as a static HTML site with one click. Internal links are automatically resolved.

### 4. Multi-Platform Distribution
Export in formats optimized for WeChat Official Accounts, Zhihu, Medium, WordPress, and more.

### 5. SEO & Social Cards
Auto-generates Open Graph tags for beautiful previews when sharing on social media.

### 6. Complete Rendering Preservation
- Mermaid diagrams ✅
- Math formulas (MathJax) ✅
- Code syntax highlighting ✅
- Task lists ✅

### 📱 Mobile-First
All exported pages use responsive design, providing a perfect reading experience on mobile devices.

## 🚀 Quick Start

1. Search for **OmniExport** in the Obsidian community plugin store and install it
2. Configure your language and theme preferences in settings
3. Use the command palette (`Ctrl/Cmd + P`) and search for:
   - `Export current note as HTML` — export the current file
   - `Batch export entire vault` — export the whole vault

## ⚙️ Settings

| Setting | Description |
|---------|-------------|
| Language | 中文 / English |
| Theme | Light / Dark / Auto |
| Embed Assets | Generate single-file HTML |
| Interactive Features | TOC, search, theme toggle |
| Mermaid | Render Mermaid diagrams |
| Math | Render LaTeX formulas |
| Code Highlight | Syntax highlighting |
| SEO | Generate Open Graph tags |
| Output Path | Custom output directory |
| Auto Update | Check for new versions automatically |
